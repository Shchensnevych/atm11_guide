# ATM11 — путівник: посібник користувача

Інтерактивний український путівник по збірці **All the Mods 11** (Minecraft 26.1.2): з чого почати, що з чим поєднувати, куди відгалужуватися.

## Як відкрити
- **Локально:** запустіть `start.bat` — відкриється http://localhost:8811 (потрібен Python; або VS Code → Live Server на теці `docs`).
- **Онлайн:** після публікації на GitHub Pages (Settings → Pages → Branch `main`, folder `/docs`).
- Подвійний клік по `docs/index.html` не спрацює: браузери не завантажують модулі й дані з файлів напряму.

## Розділи
- **Дорожня карта** — дерево розвитку згори вниз. Золотий **стовбур** посередині — головний шлях (квести «Розділ 1/2»), від нього на кожному етапі відгалужуються групи модів; етапи — на рейці зліва (клік — перейти). Перемикач **«За модами»** показує ті самі віхи сузір'ями: у центрі хаб групи, навколо — її віхи (клік по хабу — підсвітити групу).
  - Картка віхи: назва, іконки ключових предметів (наведіть — українська назва), логотипи модів (клік — сторінка мода), піктограми можливостей, ★ — знадобиться для ATM Star.
  - Стани: ✔ зроблено · ! доступно (усе потрібне виконано) · 🔒 ще не доступно. Наведення — підсвічує шлях до віхи й далі; клік — деталі праворуч; подвійний клік — «зроблено».
  - Лінії: суцільна — «потрібно для», жовта пунктирна — синергія, точкова — варіант (клік по легенді ховає тип). Пошук «Знайти мод на карті» підсвічує всі віхи мода. Колесо / два пальці — масштаб, перетягування — рух, мінікарта — швидкий перехід.
- **Моди** — довідник усіх модів збірки з бейджами класів, пошуком і фільтрами. Бібліотеки й оптимізацію приховано (галочка вгорі). Пунктирний бейдж — клас визначено автоматично, опис ще не написано.
  - Піктограми «що додає у світ»: портал — виміри, череп з короною — боси, замок — данжі й структури, ялинка — біоми, рудний блок — руди, лапа — істоти. Фільтр під класами.
- **Квести** — усі глави книги квестів українською, розкладені так само, як у грі. Клік по квесту — опис з кольорами, завдання, залежності.
- **Гілки** — окремі моди/системи для занурення (напр. Occultism): що дають для прогресу і схема кроків.
- **Клавіші** — сторінка на весь екран: ліворуч графічна клавіатура (ANSI TKL 87 або повна 104) і миша, масштаб — під ширину й висоту екрана; під нею — **закріплена картка** клавіші (клік; ✕ — закрити) або зведення зіткнень шару. Праворуч — панель на всю висоту з вкладками **«Дії»** (пошук, «За клавішами / За категоріями / За модами», фільтри) і **«План»**.
  - На клавішах — лише позначка, колір і кількість дій. Колір «Стан»: синій — одна дія · бірюзовий — кілька в різних контекстах · жовтий — можливий конфлікт · **червоний — конфлікт** · пунктир — лише в інтерфейсі; або «Категорія» — колір зони головної дії.
  - **Зони-категорії** (Рух, Бій, Інвентар, Сховища, Інструменти…): виберіть зону — назви її дій з'являться виносками навколо клавіатури з лініями до клавіш, решта клавіш притухне.
  - Наведення на клавішу — підсвітка й підказка з усіма діями (з невеликою затримкою), панель праворуч не змінюється; наведення на картку в панелі — лінія до клавіші; клік — картка клавіші під клавіатурою: усі дії за модами (посилання на моди), зіткнення, план. Шари **Shift / Ctrl / Alt / F3**, фільтр контекстів (у світі · з предметом · верхи · в інтерфейсі).
  - **Конфлікт** — дві дії різних модів, що діють завжди (обидві «у світі») або в тому самому вікні. Дії модів, які працюють лише з певним предметом у руці (чи верхи), на одній клавіші з іншими — лише **можливий** конфлікт (так задумано: різні предмети не тримаються одночасно).
  - **План перепризначень** — переносить глобальні рідковживані дії (шейдери, редактори HUD, налаштування, дублікати), клавіші модів «з предметом» лишає своїми, дає клавіші важливим діям (Ctrl+буква; Ctrl+W/A/S/D не займаємо — Ctrl це біг; лівий Alt — кругове меню Keybind Bundles). Вкладка «План» у правій панелі; перемикач **«Як зараз / З планом»** показує результат; «⬇ Рядки для options.txt» — файл для ручної заміни (при закритій грі).
  - Цифровий блок на TKL відсутній — дії на Num-клавішах показано окремим рядком.
  - **Свої клавіші:** «📂 Свій options.txt» — розбирається лише в браузері (localStorage); «↺ Дані збірки» — повернути. Або `start.bat` → «2» (потрібен Python; запускається через `py`).
  - Панель «Дії»: групування «За клавішами» (картки поточного шару в порядку клавіатури) / «За категоріями» / «За модами», пошук, фільтри «Зіткнення», «Не призначено», «★ Важливі непризначені», «🛠 У плані». На сторінці мода — блок «Клавіші».
## Прогрес (із сейву гри + у браузері)
- **Автоматично з сейву:** скрипт `tools/extract_progress.py` читає світи у `minecraft/saves/<світ>/` (`level.dat`, `ftbquests/<uuid>.json5`, `players/advancements/<uuid>.json`, `players/stats/<uuid>.json`, `players/data/<uuid>.dat`) і формує знімки прогресу:
  - За замовчуванням обирається світ, у який грали останнім, але творчі світи (`Data.GameType = 1`, напр. «Творчість») пропускаються; вибрати конкретний світ можна через `--world "<назва>"` або перемикачем світу у верхній панелі сайту.
  - На **Дорожній карті** віхи автоматично отримують стан `✔ зроблено`, якщо виконана хоча б одна умова з поля `done_by` (`quests` / `advancements` / `items`); у правій панелі віхи видно всі умови та їхній стан у сейві.
  - У розділі **Квести** глави та окремі квести на схемі позначаються кольором і значком (`✔ виконано` — зелений, `⏳ у процесі` — блакитний), а в панелі квесту виконані завдання мають позначку `✔`.
  - На **Головній** сторінці відображається зведення обраного світу (режим, час останньої гри, дата знімка, кількість виконаних віх, квестів, досягнень і здобутих предметів, активні глави квестів).
  - **Як оновити після гри:**
    1. **Прямо в браузері (без Python):** вийдіть у головне меню гри (щоб світ зберігся на диск), натисніть кнопку **«📂 Вказати теку гри»** у верхній панелі сайту (або на Головній, у вкладці «Клавіші» чи «🤖 Помічник») і виберіть теку інстансу `All the Mods 11 - ATM11` або підтеку `minecraft`. Браузер сам прочитає всі світи у `saves/<світ>/` (включно зі стиснутими Gzip NBT `level.dat` та `<uuid>.dat` через `DecompressionStream`), `options.txt` та `logs/latest.log`, одночасно оновивши прогрес світів і вкладку «Клавіші». Наступного разу достатньо натиснути **«🔄 Оновити з гри»**. Кнопка **«↺ Дані збірки»** повертає початкові дані сайту.
    2. **Через скрипт (для розробки):** запустіть `start.bat` → пункт **3** (`start.bat save`).
- **Ручні позначки у браузері:** галочки «Зроблено» зберігаються у `localStorage` окремо для кожного світу (`atm11-guide-progress-v1:<slug>`). Наявні позначки «без світу» (`atm11-guide-progress-v1`) при першому відкритті автоматично переносяться у перший вибраний світ без втрати даних.

## Класи модів і система піктограм
- **Класи модів (`classes.json` + `CLS_ICONS` у `docs/js/components/feat.js`):** Техніка · Енергія · Сховища · Логістика · Ресурси · Ферми й їжа · Магія · Спорядження · Дослідження · Боси й данжі · Декор · Зручність · Бібліотека · Оптимізація.
- **Піктограми можливостей у світі (`FEATS` у `docs/js/components/feat.js`):** виміри (`dimension`), боси (`boss`), данжі (`dungeon`), біоми (`biome`), руди (`ores`), істоти (`mobs`).
- **Уніфікація піктограм:** і класи модів (`clsIcon`), і можливості у світі (`featIcon`) рендеряться з єдиного вбудованого векторного SVG-набору (`viewBox="0 0 24 24"`, `stroke-width: 1.9`, колір через CSS-змінну `--fc` / `--c`) скрізь на сайті — на Головній, у Довіднику модів (чипи фільтрів і бейджі на картках), на сторінці мода, на Дорожній карті (чипи класів, легенда й картки віх) та в Гілках. Однотипні поняття (наприклад, клас «Боси й данжі» та можливість «боси») мають ідентичну векторну піктограму.
- **Іконки предметів і блоків (`docs/img/items/*.png` + `docs/data/items.json`):** генеруються скриптом `tools/extract_icons.py` (разом із ручними правилами `content/icons_override.json`) безпосередньо з `.jar`-файлів модів та клієнтського `.jar` Minecraft (плоскі текстури предметів, ізометричні 3D-рендери блоків, моделі Geckolib `.geo.json` та розгортки `boxes`).
- **Збереження стану сторінок (`docs/js/core/view-state.js`):** усі основні екрани путівника автоматично запам'ятовують свій стан у `sessionStorage` під час переходів:
  - **Довідник модів (`#/mods`):** зберігає вибрані класи, можливості, пошуковий запит, прапорці («бібліотеки», «лише описані», «без доповнень»), сортування та позицію прокрутки; кнопка «✕ Скинути» очищує всі фільтри.
  - **Дорожня карта (`#/roadmap`):** зберігає режим (`🌳 Дерево` / `✦ За модами`), точну позицію й масштаб полотна (`x, y, k`), відкриту в правій панелі віху, пошук мода, вибрані фільтри класів/можливостей та приховані типи ліній.
  - **Квести (`#/chapters`, `#/chapter/<файл>`), Гілки (`#/branch/<id>`), Клавіші (`#/keys`):** зберігають прокрутку списків, масштаб і панораму графа квестів Cytoscape, вибраний квест/крок гілки та активний шар/фільтр клавіш. На сторінці мода (`#/mod/<id>`) кнопка «← Назад» повертає точно на попередній екран.

## Дані прогресу (`docs/data/progress.json`, `docs/data/progress/<slug>.json`, `docs/data/progress/index.json`)
Генерує `tools/extract_progress.py [--world <назва>]`. У `roadmap.json` кожна віха має `done_by: { quests?: [hexId], advancements?: [id], items?: [id] }` (перевіряє `tools/build_data.py`).
```
{ slug:            "novyy_svit",              // латинський ідентифікатор світу (файл progress/<slug>.json)
  world:           "Новий світ",              // назва світу з level.dat (Data.LevelName)
  folder:          "Новий світ",              // назва теки в minecraft/saves/
  mode:            "survival" | "creative" | "adventure" | "spectator",
  mode_uk:         "Виживання" | "Творчість" | "Пригода" | "Спостерігач",
  game_type:       0,                         // Data.GameType з level.dat (0 — виживання, 1 — творчість)
  last_played:     "YYYY-MM-DD HH:MM",        // час останньої гри (mtime level.dat / файлів гравця)
  last_played_ts:  1792875450,                // Unix-час останньої гри
  updated:         "YYYY-MM-DD HH:MM",        // коли знято знімок прогресу
  play_hours:      1.37,                      // час у грі (год, з minecraft:play_time у stats)
  player:          { uuid, name?, xp_level, dimension, world_tier, unique_foods },
  quests:          { done: [hexId],           // виконані квести FTB (16-символьні hex-ID з десяткових long)
                     done_visible: [hexId],   // виконані квести у неприхованих главах
                     started: [hexId],        // розпочаті (ще не завершені) квести
                     tasks_done: [hexId],     // виконані завдання квестів
                     rewards_claimed: number,
                     by_chapter: { "<файл_глави>": { done: [hexId], started: [hexId] } } },
  advancements:    { done: ["ns:path", ...] },// виконані досягнення (без технічних :recipes/)
  items:           { obtained: ["ns:id", ...],// усі здобуті предмети (crafted ∪ picked_up ∪ used ∪ mined ∪ dropped ∪ inventory)
                     crafted: { "ns:id": count },
                     inventory: { "ns:id": count } }, // інвентар + EnderItems + Curios + Tool Belt з <uuid>.dat
  default?:        "novyy_svit",              // лише в docs/data/progress.json та progress/index.json
  worlds?:         [{ slug, world, folder, mode, mode_uk, last_played, last_played_ts, updated,
                      play_hours, quests_done, quests_visible_done, quests_started,
                      advancements_done, items_obtained }] }
```

## Дані вкладки «Клавіші» (`docs/data/keys.json`)
Збирає `tools/build_keys.py` (з `build_data.py`) з `raw/keys_auto.json` (`tools/extract_keys.py` ← `minecraft/options.txt` + назви з перекладу) і ручного шару `content/keys.json`.
```
{ cats:  [{id, title, icon}],                 // 12 категорій: move, combat, inv, storage, tools, gear, vehicle, magic, map, quests, ui, screen
  ctxs:  [{id, title, desc}],                 // game | held | vehicle | gui | debug
  stat:  {keys, bound, unbound, conflicts, maybe, imp_unbound, plan, plan_conflicts, plan_maybe, plan_imp_unbound},
  keys:  [{ id,        // id дії з options.txt (key_<id>), напр. "key.toolbelt.open"
            ns, mod?,  // простір імен; mod — id мода збірки (посилання #/mod/<id>), якщо є
            name, en?, // назва українською (або англійською), en — якщо відрізняється
            bind,      // "key.keyboard.r" | "key.mouse.left" | "key.keyboard.unknown" (не призначено)
            m,         // модифікатор: "" | "S" | "C" | "A"
            cat, ctx, scr?,   // категорія, контекст, екран (для gui: "c:*" — будь-яке вікно з інвентарем, "c:<ім'я>", "quests", "map"…)
            nc?,       // не конфліктує (модифікатор, що утримується; дія над конкретним елементом)
            soft?,     // діє рідко/умовно → конфлікт лише «можливий»
            imp?, note?,           // важлива; примітка
            plan?, why?,           // план перепризначення: «Ctrl+G» | «F8» | «none» (зняти) і причина
            extra? }] }            // дія з власного options.txt, якої немає в збірці
```
Конфлікт (`core/keys-model.js` level = `build_keys.py` level): однакове сполучення (шар + клавіша) у дій різних модів, обидві не `nc`: у світі × у світі → **конфлікт**; у світі/з предметом × з предметом, верхи × у світі/з предметом, `soft` → **можливий**; інтерфейс × інтерфейс — конфлікт на тому самому екрані, можливий — якщо один із них «будь-яке вікно з інвентарем»; F3 × F3 — конфлікт.
