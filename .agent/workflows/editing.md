# Редагування файлів
- Кирилиця: не використовувати `sed` / PowerShell `-replace` для JS/JSON/MD — лише Python (`open(..., encoding='utf-8')`) або Node (`fs.readFileSync(f, 'utf8')`), з перевіркою, що заміна знайшлась рівно один раз.
- `docs/data/` і `raw/` — генеруються; руками не редагувати. Вміст — у `content/`, потім `python3 -I tools/build_data.py`.
- Один модуль — одна відповідальність, до ~300 рядків; нова сторінка — новий файл у `docs/js/views/`.
- Після правок JS — перевірити в браузері (консоль без помилок).
- Копіювання з хмари на пристрій (device_commit_files): кожна версія файлу — за новим проміжним шляхом (`outputs/sync/<md5>/…`), після коміту — `md5sum` на пристрої; коміт і читання файлу — окремими кроками.
- Дорожня карта: розкладку не задавати координатами — лише `stage`, `lane` (бік), `trunk`, порядок вузлів у roadmap.json; налагодження — `#/roadmap?elk.<параметр>=…`.
