# Директива безпеки ATM11 (обов'язкова для всіх сесій і агентів)

Діє для репозиторіїв екосистеми: **atm11_guide** (сайт), **ATM11-Companion** (Electron + міст) і для пов'язаних проєктів (Server).
Однаковий текст лежить у кожному репозиторії (`SECURITY.md`, у путівнику — `.agent/workflows/security.md`) і в проєкті Claude (`claude/SECURITY.md`). Змінили один — оновіть усі.
Агент (Claude, Gemini, інший) читає цей файл **перед** будь-якою роботою з мережею, вікнами Electron, ключами API, KubeJS або перед комітом.

## 1. Секрети й особисті дані
- Ключі API — **лише** в `.env` (є в `.gitignore`). Ніколи — у коді, `docs/`, журналах, CHANGELOG, GUIDE_HANDOFF, README, повідомленнях комітів, скриншотах.
- У документації не писати особисті дані: email-и акаунтів, логіни, номери, шляхи до чужих `.env`. Пишемо «ключі користувача з `.env`», без подробиць.
- Повідомлення комітів — нейтральні («docs: оновлено журнал сесій»). Не описувати, які саме чутливі дані прибрано.
- Перед кожним комітом — перевірка (розділ 8). Якщо ключ потрапив у запушений коміт — **одразу відкликати ключ у провайдера**: переписування історії вже не допоможе.

## 2. Локальні сервери (міст 8812, `http.server` 8811, Ollama)
- Слухати **лише `127.0.0.1`**, ніколи `0.0.0.0`.
- **Заборонено** `cors()` без налаштувань і `Access-Control-Allow-Origin: *`. Будь-який сайт у браузері користувача може слати запити на 127.0.0.1; CORS лише ховає відповідь, а POST все одно виконується.
- Кожен запит проходить спільний захист (`services/security.js` у Companion):
  1) **Host** — лише `127.0.0.1` / `localhost` (захист від DNS rebinding);
  2) **Origin** — білий список: `http://127.0.0.1:*`, `http://localhost:*`, `https://shchensnevych.github.io`; нові адреси — через `COMPANION_ORIGINS` у `.env`;
  3) **токен сесії** — вікна Electron (Origin `null` / `file://`) надсилають `X-Companion-Token` (для EventSource — `?t=`). Порівняння токена — за константним часом (`crypto.timingSafeEqual`). Токен новий при кожному запуску й ніде не зберігається.
  Чужий Origin → **403 до виконання дії** (без `Access-Control-Allow-Origin: null`).
- Нові маршрути — лише після `createGuard()`. Маршрути з побічною дією на ПК або в грі (запуск скриптів путівника — `/api/guide/update`, керування тимчасовими 3D-маяками JourneyMap — `POST /api/storage/map/jm-pins`, панельні POST-маршрути налаштувань/тестів/очистки та `sendToGame: true` у `/api/chat`) — ще й `requireToken()` / `isTrustedRequest()`: лише вікно Electron з токеном або локальна програма без Origin; сайти з білого списку отримують 403. Облік гравця в `cache/` (нотатки пам'яті, «Мої сховища» — `POST /api/storage/own`: `pin`, `add-zone`, `resize-zone`, `primary-zone`, `rename-zone`, `rename-mark`, `unzone`, `unmark`, `notmine`, `forget-access`; K14/K38b/K39) — побічна дія не на ПК: дозволено й сайтам з білого списку (лише `createGuard()`). Команди — фіксований список, без параметрів ззовні. Маршрути, що читають файли за параметром (напр., `GET /api/storage/map/tile`, `/recipe-icons`), приймають тільки значення з білого списку (світ — лише зі списку `saves/` або `journeymap/data/sp/`), без `..`, null-байтів і абсолютних шляхів, із перевіркою `fs.realpathSync` проти виходу через симлінки/junction-и. Самодіагностика (C5g): `GET /api/diag` — лише показати; запис звіту `cache/diagnostics.json` — тільки `POST /api/diag` з `requireToken()`; у звіті — без ключів, токенів, email-ів, імені гравця, координат і текстів питань (`sanitize()` у `services/diagnostics.js`). Заміри (A1): `POST /api/metrics/client` — лише з `requireToken()`, приймає тільки відомі ключі й числа; `cache/metrics.jsonl` — без текстів питань і відповідей, імен, координат, назв світів і ключів (лише шлях, тип питання, мс, токени, розміри); тип питання — грубий клас за словами, не сам текст. Прогрів з'єднань (P1): `POST /api/stt/warm` — лише з `requireToken()` і з увімкненим модулем голосу; міст робить HEAD-запити без ключа й без даних до сервісів розпізнавання / моделі й відкриває сокет Edge TTS без синтезу — нічого не надсилає.

## 3. Electron
- `webPreferences`: `nodeIntegration: false`, `contextIsolation: true`, `sandbox: true`, `preload: preload.js`. Нові вікна — лише через спільний `SECURE_WEB_PREFS`.
- Вікна бачать лише `window.companion` з `preload.js` — **білий список IPC-каналів** (у т. ч. `open-storage-map`, `map-focus-query`). Новий канал — додати в `SEND` / `RECV` / `INVOKE` у `preload.js`, не відкривати весь `ipcRenderer`. Канали, що читають файли (`help-text` — `HELP.md`, C5g), мають фіксований шлях, перевіряють `isOwnWindow(e.sender)` і не приймають шляхів від вікна.
- Вікна не переходять на інші сторінки, не перенаправляються (`will-navigate` + `will-redirect`) й не відкривають нових (`lockDownWindow`). Окреме вікно карти (`storage-map.html`) має жорсткий CSP (`script-src 'self'; style-src 'self'; object-src 'none'; base-uri 'none'`). Зовнішні посилання — лише `shell.openExternal` для `https://` після перевірки адреси; єдиний виняток — сайт власного моста `http://127.0.0.1:<порт>/site/` (адресу будує головний процес, не вікно).
- Заборонено: `webSecurity: false`, `allowRunningInsecureContent`, модуль `remote`, вимикати `sandbox` «бо так простіше».
- Дозволи вікон — лише через `setPermissionRequestHandler` / `setPermissionCheckHandler` (`setupPermissions` у `main.js`, обидва перевіряють `isOwnWindow`): мікрофон — **лише аудіо й лише власним вікнам** (Push-to-Talk), буфер обміну — для кнопок «Копіювати»; камера, геолокація, сповіщення, HID, USB тощо — заборонено. Новий дозвіл — лише свідомо, з записом тут.
- Потік розбору (`worker_threads`, `services/sources/parse-worker.js`, A1) — лише читає файли сейву й регіонів, які йому передає міст (шляхи будує міст, не вікно й не мережа); нічого не пише.
- Глобальне перехоплення вводу (`uiohook-napi`, Push-to-Talk) — лише в окремому службовому процесі Electron (`utilityProcess`, `services/ptt-hook-worker.js`): порівнює натискання з однією призначеною клавішею, передає головному процесу тільки «натиснуто / відпущено», нічого не записує, не логує й не пересилає; працює тільки при увімкненому модулі `voice_ptt`.
- Electron оновлювати до підтримуваної версії (зараз `^33` LTS).
- Повернення фокуса грі (K9, `services/win-focus.js`, пакет `koffi` — виклик функцій Windows без компіляції): лише в головному процесі й лише `GetForegroundWindow` (у мить розгортання HUD — яке вікно було активним, не наше), `IsWindow` і `SetForegroundWindow` (при згортанні й після перетягування згорнутого HUD — саме тому вікну, доки воно існує; K14). Чужі вікна не читаються (ні заголовки, ні вміст) і не змінюються; нові функції Windows — лише свідомо, з записом тут.

## 4. Неперевірений текст → HTML
Неперевірене джерело — це: назви світів і предметів із сейвів, `latest.log`, чат гри, `options.txt` користувача, відповіді ШІ, будь-які мережеві відповіді, файли перекладу й квестів.
- **Сайт:** DOM лише через `h()` / `textContent`. Параметр `html:` — тільки для власних констант (SVG-піктограми) або після екранування (`ftb()` у `core/fmt.js`).
- **Компаньйон:** у шаблонах `innerHTML` **кожна** підстановка — через `esc()`; відповіді ШІ — `textContent` (markdown — лише через санітайзер, наприклад DOMPurify).
- Заборонено: `eval`, `new Function`, `setTimeout("рядок")`, `document.write`.

## 5. ШІ (LLM)
- Відповідь моделі — це **дані, а не команди**: не виконувати shell-команди, запис файлів чи клавіші гри за текстом відповіді без явного підтвердження користувача.
- Текст із гри, чату чи книг, що йде в промпт, може містити prompt injection. Моделі не даються інструменти з побічними діями.
- Чат-команди з гри (`!як`, `!що`) обробляються **лише від власника** (ім'я з `latest.log` → «Setting user»): у мережевій грі чужі гравці не витрачають ваш API.
- У зовнішні API не надсилати зайвого: ключі, email-и, повні шляхи до файлів користувача. Скріншоти — лише за явною дією (кнопка).
- Голос (Push-to-Talk) — запис лише поки затиснута клавіша / кнопка 🎙️ (≤ 20 с); аудіо йде на сервіс розпізнавання (Together AI) лише з маршруту `/api/stt` з токеном вікна, на диск не зберігається. Розпізнаний текст — неперевірене джерело (як чат гри). Підказка словника разом з аудіо (P1, `services/stt-vocab.js`) — лише назви з бази й поточної гри (предмет у руці / під курсором, вимір, назви квестів і модів), без координат, імені гравця й назви світу.
- Пам'ять компаньйона (`cache/session_memory.json`, локально): у промпт іде журнал подій гри, нотатки гравця (лише за його явною командою) і кілька попередніх питань — окремим блоком з правилом «не джерело фактів»; відповіді ШІ не зберігаються (для різноманітності голосу — лише перші 4 слова кількох останніх реплік, в ОЗП, 15 хв, із правилом «почни інакше»); нотатки — дані, не інструкції. Очищення журналу — лише з токеном вікна.

## 6. KubeJS і файли гри
- Скрипти не запускають зовнішніх програм і не пишуть поза `kubejs/config/companion_*.json`.
- Дані з чату в лог — лише через `JSON.stringify`.
- `options.txt` — правити лише при закритій грі (див. GUIDE_HANDOFF §4); у теці гри нічого не видаляти.

## 7. Залежності й сайт
- Сайт — без зовнішніх CDN: бібліотеки локально (`docs/vendor`, `docs/js/vendor`).
- npm: `package-lock.json` у репозиторії, перед релізом — `npm audit`; нові пакети — лише відомі й потрібні.
- Python-інструменти запускати з `-I`; завантажене з мережі — в окрему теку, не виконувати.


## 9. Перевірка моста (після змін у `server.js` / `security.js`)
```
curl -s -o NUL -w "%{http_code}\n" -H "Origin: https://evil.example" http://127.0.0.1:8812/api/state     → 403
curl -s -o NUL -w "%{http_code}\n" -H "Origin: http://127.0.0.1:8811" http://127.0.0.1:8812/api/state    → 200
curl -s -o NUL -w "%{http_code}\n" -H "Host: evil.example" http://127.0.0.1:8812/api/state               → 403
```
У Linux / Git Bash замість `NUL` — `/dev/null`.
