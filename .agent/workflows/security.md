# Директива безпеки ATM11 (обов'язкова для всіх сесій і агентів)

Діє для всіх репозиторіїв екосистеми: **atm11_guide** (сайт), **ATM11-Companion** (Electron + міст), **ATM11-UA** (ресурспак + KubeJS) і для пов'язаних проєктів (Server).
Однаковий текст лежить у кожному репозиторії (`SECURITY.md`, у путівнику — `.agent/workflows/security.md`) і в проєкті Claude (`claude/SECURITY.md`). Змінили один — оновіть усі.
Агент (Claude, Gemini, інший) читає цей файл **перед** будь-якою роботою з мережею, вікнами Electron, ключами API, KubeJS або перед комітом.

## 1. Секрети й особисті дані
- Ключі API — **лише** в `.env` (є в `.gitignore`). Ніколи — у коді, `docs/`, журналах, CHANGELOG, GUIDE_HANDOFF, README, повідомленнях комітів, скриншотах.
- У документації не писати особисті дані: email-и акаунтів, логіни, номери, шляхи до чужих `.env`. Пишемо «ключі користувача з `.env`», без подробиць.
- Повідомлення комітів — нейтральні («docs: оновлено журнал сесій»). Не описувати, які саме чутливі дані прибрано.
- Перед кожним комітом — перевірка (розділ 8). Якщо ключ потрапив у запушений коміт — **одразу відкликати ключ у провайдера**: переписування історії вже не допоможе.

## 2. Локальні сервери (міст 8812, `http.server` 8811, Ollama)
- Слухати **лише `127.0.0.1`**, ніколи `0.0.0.0`.
- **Заборонено** `cors()` без налаштувань і `Access-Control-Allow-Origin: *`. Будь-який сайт у браузері користувача може слати запити на 127.0.0.1; CORS лише ховає відповідь, а POST все одно виконується.
- Кожен запит проходить спільний захист (`services/security.js` у Companion):
  1) **Host** — лише `127.0.0.1` / `localhost` (захист від DNS rebinding);
  2) **Origin** — білий список: `http://127.0.0.1:*`, `http://localhost:*`, `https://shchensnevych.github.io`; нові адреси — через `COMPANION_ORIGINS` у `.env`;
  3) **токен сесії** — вікна Electron (Origin `null` / `file://`) надсилають `X-Companion-Token` (для EventSource — `?t=`). Токен новий при кожному запуску й ніде не зберігається.
  Чужий Origin → **403 до виконання дії**.
- Нові маршрути — лише після `createGuard()`. Маршрути з побічною дією на ПК (запуск скриптів путівника — `/api/guide/update`) — ще й `requireToken()`: лише панель з токеном або локальна програма без Origin; сайти з білого списку отримують 403. Команди — фіксований список, без параметрів ззовні. Маршрути, що читають файли за параметром, приймають тільки значення з білого списку (наприклад, світ — лише зі списку `saves/`), без `..` і абсолютних шляхів.

## 3. Electron
- `webPreferences`: `nodeIntegration: false`, `contextIsolation: true`, `sandbox: true`, `preload: preload.js`. Нові вікна — лише через спільний `SECURE_WEB_PREFS`.
- Вікна бачать лише `window.companion` з `preload.js` — **білий список IPC-каналів**. Новий канал — додати в `SEND` / `RECV` у `preload.js`, не відкривати весь `ipcRenderer`.
- Вікна не переходять на інші сторінки й не відкривають нових (`lockDownWindow`). Зовнішні посилання — лише `shell.openExternal` для `https://` після перевірки адреси; єдиний виняток — сайт власного моста `http://127.0.0.1:<порт>/site/` (адресу будує головний процес, не вікно).
- Заборонено: `webSecurity: false`, `allowRunningInsecureContent`, модуль `remote`, вимикати `sandbox` «бо так простіше».
- Electron оновлювати до підтримуваної версії (зараз `^27` — застаріла гілка, оновити в окремій сесії з перевіркою HUD).

## 4. Неперевірений текст → HTML
Неперевірене джерело — це: назви світів і предметів із сейвів, `latest.log`, чат гри, `options.txt` користувача, відповіді ШІ, будь-які мережеві відповіді, файли перекладу й квестів.
- **Сайт:** DOM лише через `h()` / `textContent`. Параметр `html:` — тільки для власних констант (SVG-піктограми) або після екранування (`ftb()` у `core/fmt.js`).
- **Компаньйон:** у шаблонах `innerHTML` **кожна** підстановка — через `esc()`; відповіді ШІ — `textContent` (markdown — лише через санітайзер, наприклад DOMPurify).
- Заборонено: `eval`, `new Function`, `setTimeout("рядок")`, `document.write`.

## 5. ШІ (LLM)
- Відповідь моделі — це **дані, а не команди**: не виконувати shell-команди, запис файлів чи клавіші гри за текстом відповіді без явного підтвердження користувача.
- Текст із гри, чату чи книг, що йде в промпт, може містити prompt injection. Моделі не даються інструменти з побічними діями.
- Чат-команди з гри (`!як`, `!що`) обробляються **лише від власника** (ім'я з `latest.log` → «Setting user»): у мережевій грі чужі гравці не витрачають ваш API.
- У зовнішні API не надсилати зайвого: ключі, email-и, повні шляхи до файлів користувача. Скріншоти — лише за явною дією (кнопка).

## 6. KubeJS і файли гри
- Скрипти не запускають зовнішніх програм і не пишуть поза `kubejs/config/companion_*.json`.
- Дані з чату в лог — лише через `JSON.stringify`.
- `options.txt` — правити лише при закритій грі (див. GUIDE_HANDOFF §4); у теці гри нічого не видаляти.

## 7. Залежності й сайт
- Сайт — без зовнішніх CDN: бібліотеки локально (`docs/vendor`, `docs/js/vendor`).
- npm: `package-lock.json` у репозиторії, перед релізом — `npm audit`; нові пакети — лише відомі й потрібні.
- Python-інструменти запускати з `-I`; завантажене з мережі — в окрему теку, не виконувати.

## 8. Чекліст перед комітом / пушем
```
git diff --cached --stat
git diff --cached | grep -nE "(sk-or-v1-|tgp_v1_|sk-ant-|sk-proj-|AIza|hf_)[A-Za-z0-9_-]{12}|@gmail\.com|@ukr\.net|BEGIN [A-Z ]*PRIVATE KEY"
git ls-files | grep -iE "(^|/)\.env$|\.pem$|\.key$"
```
Усі три команди мають не знайти нічого (крім `.env.example` без значень).

## 9. Перевірка моста (після змін у `server.js` / `security.js`)
```
curl -s -o NUL -w "%{http_code}\n" -H "Origin: https://evil.example" http://127.0.0.1:8812/api/state     → 403
curl -s -o NUL -w "%{http_code}\n" -H "Origin: http://127.0.0.1:8811" http://127.0.0.1:8812/api/state    → 200
curl -s -o NUL -w "%{http_code}\n" -H "Host: evil.example" http://127.0.0.1:8812/api/state               → 403
```
У Linux / Git Bash замість `NUL` — `/dev/null`.
