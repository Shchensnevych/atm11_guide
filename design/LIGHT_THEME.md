# ☀️ Специфікація світлої теми (Light Theme Specification)

> **Проєкт**: ATM11 Guide (`atm11_guide`)  
> **Концепція дизайну**: «Slate Paper / Матовий папір»  
> **Статус**: Готово до впровадження  
> **Ціль**: Зручне читання путівника вдень та при яскравому освітленні зі збереженням високої контрастності, чіткості векторних графів та ігрових спрайтів Minecraft.

---

## 1. Концепція «Slate Paper» (Чому не сліпучо білий)

Чисто білий фон (`#ffffff`) створює надмірне навантаження на зір («ефект прожектора») і знищує деталізацію світлих текстур Minecraft (кварц, залізо, біла вовна, пір'я, сніг).

Тому світла тема базується на **палітрі Slate (благородний світлий камінь / матовий папір)**:
- **Тло сторінки (`--bg`)**: м'який світло-сірий відтінок `#f4f6f9`.
- **Картки (`--panel`)**: чистий білий `#ffffff`, що візуально піднімає контент над тлом без кричущих тіней.
- **Підкладки під іконки (`--panel-2`)**: приглушений попелястий `#e8edf4`, який створює чіткий п'єдестал для будь-яких світлих спрайтів.
- **Текст (`--text`)**: глибокий графіт `#0f172a` (Slate-900), контрастність понад **14:1** (перевершує стандарт WCAG AAA).

## 2. Матриця токенів кольорів (`docs/css/tokens.css`)

Усі глобальні кольори перевизначаються через селектор `[data-theme="light"]`:

```css
[data-theme="light"] {
  /* Основні фони та поверхні */
  --bg: #f4f6f9;                          /* Загальне тло сторінки */
  --bg-2: #e9eef5;                        /* Панелі інструментів, бічні рейки, шапка */
  --panel: #ffffff;                       /* Тло карток, модальних вікон */
  --panel-2: #e8edf4;                     /* Підкладки під логотипи та іконки предметів */

  /* Лінії та роздільники */
  --line: #cbd5e1;                        /* Чіткі межі карток і блоків (Slate-300) */
  --line-2: #94a3b8;                      /* Пунктирні та точкові роздільники (Slate-400) */

  /* Типографіка */
  --text: #0f172a;                        /* Основний текст (Slate-900, максимальна чіткість) */
  --muted: #64748b;                       /* Підписи, другорядний текст (Slate-500, контраст 5.2:1) */

  /* Акценти та стани (адаптовані під світлий фон) */
  --accent: #d97706;                      /* Теплий бурштин (замість блідо-жовтого, ховер і фокус) */
  --accent-2: #b45309;                    /* Глибокий бурштин для активних натискань */
  --link: #0284c7;                        /* Глибокий небесно-блакитний (Sky-600, стан «У процесі») */
  --ok: #16a34a;                          /* Смарагдово-зелений (Green-600, стан «Виконано») */
  --warn: #ea580c;                        /* Помаранчевий (Orange-600, попередження) */
  --bad: #dc2626;                         /* Червоний (Red-600, приховані глави, конфлікти) */

  /* Тіні */
  --shadow: 0 4px 20px rgba(15, 23, 42, 0.08);
}
```

## 3. Збереження контрасту ігрових спрайтів Minecraft

### Проблема
У Minecraft десятки популярних предметів мають білий або напівпрозорий силует (залізні злитки, кристали сертусу, кварц, кістки, незерит із білим відблиском). На білому тлі вони зливаються з карткою.

### Технічне рішення
1. **Ізолюючий п'єдестал**:
   Усі контейнери іконок (`.ch-ic`, `.mod-logo`, `.item-slot`) у світлій темі мають непрозоре попелясте тло:
   ```css
   [data-theme="light"] .chapter-card .mod-logo,
   [data-theme="light"] .chapter-card .ch-ic,
   [data-theme="light"] .mod-card-head .mod-logo {
     background: var(--panel-2);           /* #e8edf4 */
     border: 1px solid var(--line);        /* #cbd5e1 */
     border-radius: 10px;
   }
   ```
2. **Мікро-тінь для спрайтів**:
   Для прозорих PNG застосовується делікатний контурний фільтр:
   ```css
   [data-theme="light"] .chapter-card .ch-ic,
   [data-theme="light"] .mod-logo img {
     filter: drop-shadow(0 1px 2px rgba(15, 23, 42, 0.15));
   }
   ```

## 4. Картки квестів (схема F) та картки модів

### А. Картка квестів (`.chapter-card`)
- **Роздільники**: тонка вертикальна та горизонтальна лінії використовують токен `--line-2` (`#94a3b8`).
- **Блок лічильника**: великі цифри стають насичено темними (`#0f172a`), підпис `квестів` — кольору `--muted` (`#64748b`).
- **Світлові стани карток**:
  ```css
  /* У процесі */
  [data-theme="light"] .chapter-card.ch-part {
    border-color: var(--link);
    box-shadow: 0 0 0 1px rgba(2, 132, 199, 0.25), 0 4px 16px rgba(2, 132, 199, 0.08);
  }
  /* Виконано */
  [data-theme="light"] .chapter-card.ch-done {
    border-color: var(--ok);
    box-shadow: 0 0 0 1px rgba(22, 163, 74, 0.25), 0 4px 16px rgba(22, 163, 74, 0.08);
  }
  /* Наведення */
  [data-theme="light"] .chapter-card:hover {
    border-color: var(--accent);
    box-shadow: 0 6px 20px rgba(217, 119, 6, 0.15);
  }
  ```

### Б. Чипи класів та бейджі
У світлій темі підкладка чипів не повинна бути перенасиченою:
```css
[data-theme="light"] .chip.on {
  background: color-mix(in srgb, var(--c) 12%, #ffffff);
  border-color: var(--c);
  color: #0f172a;
  box-shadow: 0 1px 3px rgba(15, 23, 42, 0.06);
}
```

## 5. Дорожня карта (ELK.js SVG-полотно)

### А. Точкова інженерна сітка (`<pattern id="dot-grid">`)
- Точки перефарбовуються у делікатний колір `#cbd5e1` (розмір точок 1.2 px, крок 24 px).
- Створює відчуття якісного світлого міліметрового креслярського паперу.

### Б. Векторні шляхи (SVG Edges)
- **Суцільні лінії (передумови)**: `stroke: #64748b` (Slate-500), товщина 2 px.
- **Пунктирні лінії (синергії)**: `stroke: #0284c7` (Sky-600), `stroke-dasharray: 6 4`.
- **Точкові лінії (альтернативи)**: `stroke: #ea580c` (Orange-600), `stroke-dasharray: 2 4`.
- **Стрілочки-маркери**: отримують `fill: context-stroke`, що автоматично синхронізує колір вістря з лінією.
- **Активна лінія (підсвітка віхи)**:
  `stroke: #0284c7`, товщина 3.5 px, ефект `filter: drop-shadow(0 2px 4px rgba(2, 132, 199, 0.35))`.

## 6. Інтерактивний граф квестів (Cytoscape.js)

Оскільки Cytoscape рендерить елементи на полотні HTML5 Canvas, стилі задаються програмно через JS-функцію:

```javascript
export function getCyThemeStyles(isLight) {
  return [
    {
      selector: 'core',
      style: {
        'selection-box-color': isLight ? '#0284c7' : '#7cc4ff',
        'selection-box-opacity': 0.2
      }
    },
    {
      selector: 'node',
      style: {
        'background-color': isLight ? '#ffffff' : '#151d28',
        'border-color': isLight ? '#cbd5e1' : '#33435a',
        'border-width': 1.5,
        'color': isLight ? '#0f172a' : '#e6edf3',
        'font-family': 'Segoe UI, system-ui, sans-serif',
        'font-size': '11px'
      }
    },
    {
      selector: 'edge',
      style: {
        'line-color': isLight ? '#94a3b8' : '#33435a',
        'target-arrow-color': isLight ? '#94a3b8' : '#33435a',
        'width': 2,
        'curve-style': 'bezier'
      }
    },
    {
      selector: 'node.q-done',
      style: {
        'border-color': isLight ? '#16a34a' : '#4ade80',
        'border-width': 2
      }
    },
    {
      selector: 'node.q-part',
      style: {
        'border-color': isLight ? '#0284c7' : '#7cc4ff',
        'border-width': 2
      }
    }
  ];
}
```

При кліку на перемикач теми в шапці активний граф моментально оновлюється без перезавантаження сторінки:
```javascript
cy.style(getCyThemeStyles(theme === 'light')).update();
```

## 7. Вкладка «Клавіші» (ANSI TKL Клавіатура)

- **Корпус клавіатури**: матовий пластик `#e2e8f0` (Slate-200) з делікатним обідком `#cbd5e1`.
- **Кейкапи (клавіші)**: 
  - Тло клавіші: чистий білий `#ffffff`.
  - Межа клавіші: `#cbd5e1`.
  - Нижня тінь (3D-ефект клавіші): `box-shadow: 0 2px 0 #94a3b8, 0 3px 6px rgba(15, 23, 42, 0.08)`.
  - Символи на клавішах: насичений графіт `#0f172a`, напівжирний шрифт.
- **Підсвітка зон (12 категорій)**:
  Замість кислотних неонових кольорів клавіші отримують пастельне тоноване тло з яскравою кольоровою смужкою вгорі кейкапа.

## 8. Механізм перемикання теми (Zero FOUC)

Щоб запобігти неприємному блиманню («спалаху» іншої теми) під час оновлення сторінки:

1. **Інлайн-скрипт у `<head>` (`index.html`)**:
   Виконується миттєво ще до побудови DOM:
   ```html
   <script>
     (function() {
       const saved = localStorage.getItem('atm11-theme');
       const systemLight = window.matchMedia('(prefers-color-scheme: light)').matches;
       const theme = saved || (systemLight ? 'light' : 'dark');
       document.documentElement.setAttribute('data-theme', theme);
     })();
   </script>
   ```

2. **Кнопка-перемикач у шапці (`.topbar`)**:
   Розміщується праворуч біля вибору світу:
   - Іконка `🌙` (якщо зараз темна) / `☀️` (якщо зараз світла).
   - Плавний перехід кольорів: `transition: background 0.2s ease, color 0.2s ease`.

## 9. Порядок впровадження

1. **Етап 1**: Створення модуля `docs/js/core/theme.js` та інтеграція перемикача в шапку (`app.js`).
2. **Етап 2**: Додавання секції `[data-theme="light"]` у `tokens.css` та базових стилів у `base.css` / `layout.css`.
3. **Етап 3**: Налаштування карток модів, квестів та чипів у `components.css`.
4. **Етап 4**: Адаптація векторної сітки та ліній дорожньої карти у `tree.css` та `tree-svg.js`.
5. **Етап 5**: Адаптація стилів графа Cytoscape (`quests-cy.js`) та кейкапів клавіатури (`keys.css`).
6. **Етап 6**: Перевірка контрастності всіх екранів через Chrome DevTools.
